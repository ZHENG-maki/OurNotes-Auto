# 自动演出（ZHENG-maki 修改版，免费开源）

本功能在 ChissaQAQ 的 OurNotes-Auto 0.2.0 基础上修改。

## 界面操作

1. 重新打开 MFAAvalonia，连接要使用的 MuMu 实例。
2. 只勾选「自动演出」任务。
3. 在任务选项的歌曲下拉列表中选择实际歌曲（曲名后标有歌曲 ID），选择实际难度，设置等待秒数（默认 600，范围 1–3600）。
4. 启动任务，看到「已准备 …，等待游戏开始」后，在游戏里手动选择同一首歌和难度、开始演出。
5. 脚本等待首音符出现，用它的下落轨迹同步；同步后不再截图，完全按谱面演奏这一局，结束后任务完成。

等待阶段不负责导航或点击开始。可在界面停止任务。等待超时或首音符同步失败会报错退出，不会自动暂停重试，也不会自动进入下一局。

歌曲必须与游戏实际曲目一致；随机模式中请先确定实际歌曲，再从下拉列表选择并启动任务。此功能不自动识别随机结果。
歌曲和难度均通过下拉列表选择。当前歌曲列表包含 93 首有谱面的歌曲，界面按语言显示曲名。新增歌曲后可刷新公开曲目缓存，再运行 `python tools/update_manual_songs.py --cache-dir cache/charts` 更新列表并重开界面。

## 条件与限制

- 继续使用原项目支持的 MuMu、16:9 画面、流速/几何设置和触控后端。
- 请在首音符出现前启动任务并等到「已准备」提示；首次使用曲目需要先下载谱面。
- 此功能不识别暂停按钮，不检测生命值或连击，也不自动暂停、重试、点击结算页；全局连击监视开关对它无效。
- 同步仍需足够的首音符轨迹。特别早的首音符或演奏画面出现过晚时，可能同步失败。
- 沿用已有全局及谱面 offset；这一入口不操作结算页，不写入结算统计或自动学习新的 offset。

## 命令行

在安装目录运行：

```powershell
.\python\python.exe -m ournotes_auto auto-play "春日影" --difficulty expert --timeout 600
```

默认设备地址以配置为准。使用其他实例时通过原有 `--set device.instance=…`、`--set device.adb_serial=…` 等参数指定，或直接使用图形界面选择实例。
